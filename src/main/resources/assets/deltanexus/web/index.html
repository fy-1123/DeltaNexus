刷兵系统

零活动刷兵：不自动刷兵、无冷却/波次，只有在这里（或指令）明确执行时才刷一次。 配置分三层——全局保护（总开关 / 黑名单 / 上限）、日志、世界层（刷兵器 + 点位组）。 点位坐标可以直接从在线玩家取：选一个玩家点「取该玩家坐标」即可填入。

全局保护
总开关关闭时下列上限全部不生效（默认关闭）
黑名单世界通配符 * ?，匹配维度 id 或世界文件夹名；每行一条
单世界实体上限超过则拒绝刷兵（0 = 不限制）
单区块实体上限按刷兵点所在区块统计
最低 TPS低于此值拒绝刷兵（0 ~ 20）
最低剩余内存 %低于此值拒绝刷兵
日志
日志级别off / error / warn / info / debug
记录内容按级别与开关决定打印
输出目标控制台 / 文件
日志文件路径相对路径 = 服务器根目录
在线玩家位置来自当前服务器；「取该玩家坐标」会把玩家当前维度与坐标一起填入并提示维度是否匹配执行维度。

点位引用留空 = 用本刷兵器的全部点位；也可写点位名或 group:组名
难度条件逗号分隔，留空 = 不限（peaceful/easy/normal/hard）
最少在线人数0 = 不限
